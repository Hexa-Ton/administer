# Responsible use

administer is a web path discovery tool: it checks which URLs respond on a
target, nothing more. It does not guess credentials, exploit anything, or
bypass authentication.

**Only run it against systems you own or have explicit, documented
permission to test.** Scanning a target you do not control without
authorization may be illegal where you live and where the target is hosted.

## Reporting a vulnerability in administer itself

If you find a security issue in this tool's own code (not a finding from
using it against a target), please open a private report via GitHub's
"Report a vulnerability" button on the Security tab of this repo, rather
than a public issue.
